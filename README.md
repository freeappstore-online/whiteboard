# Whiteboard

Simple drawing canvas. Brush colors, sizes, eraser, undo. Download as PNG.

**Category:** Productivity  
**Live:** [whiteboard.freeappstore.online](https://whiteboard.freeappstore.online)

## Development

```bash
pnpm install
pnpm dev
```

## Deploy

Push to main — auto-deploys to R2 via GitHub Actions.
